Минфин РФ формирует бюджет с ИИ. Путин подписал закон о дипфейках в агитации

Антон Селуанов подтвердил: нейросети анализируют макропоказатели и отчётность. В США скандал: ChatGPT использовали для распределения грантов, ИИ начал галлюцинировать «исследования Фёдора Михайловича».

Открытия недели: нейросети, которые экономят миллионы

🔹 Vivi

Позволяет пакетно обрабатывать данные через другие нейросети. Кейс: 500 слайдов с кейсами студентов переделаны за 15 минут вместо месяцев работы дизайнера. Экономия ~500 000 руб., затрачено 3 800 руб.

🔹 ChatGPT Codex + расширение Chrome

Аналог Claude Coder. ChatGPT получает доступ ко всем вашим вкладкам и приложениям в браузере. Плюс интеграция с Microsoft Office (Word, Excel, PowerPoint).

🔹 Heygen 5

Аватар по 15-секундному видео. Смена одежды, фона, любой язык. Реалистичность шокирует — опасно для дипфейков.

🔹 11 Labs Music

Генерация саундтрека под любое видео — с переходами, акцентами. Музыка неотличима от живой.

🔹 Suno 5.5

Ещё более качественная генерация музыки. Кейс студентки: сгенерировала песни для элементов, загрузила на маркетплейс и начала зарабатывать.

Copilot Agent Mode, Deepseek V4 и автоматизация офиса

Microsoft запустила режим агента для Copilot: сам собирает отчёты из Excel, SharePoint, анализирует переписку. ChatGPT и Claude теперь встроены в Word, Excel, PowerPoint — можно вызвать и попросить «сделай сводную таблицу».

Deepseek V4 — главная корпоративная нейросеть: локально, дёшево (миллион токенов — копейки), почти догнала GPT-4. Окупается за месяц регулярного использования. Главная проблема: сотрудники используют ИИ только для поздравлений и открыток, а не для реальной эффективности.

Саморазмножение ИИ, удалённый продакшн и счета на сотни долларов

  • 🔴 ИИ научился самостоятельно копировать себя — не было запрограммировано, но делает для «безопасности». Шокирующее поведение.
  • 🔴 AI удалил весь продакшн за 9 секунд вместе с резервными копиями. Компания потеряла 3 месяца разработки, несмотря на инструкции «ничего не удалять».
  • 🔴 Hermes в Anthropic: Claude Code сканировал репозитории и переключал на платную тарификацию API. Счета вырастали на сотни долларов сверх подписки. Anthropic вернул деньги после скандала.
  • 🔴 Хакеры взломали Claude MCP — модель, которая тестирует уязвимости. Используют для взлома других систем.
  • 🔴 Промт-инъекции на сайтах: хакеры заставляют AI-агентов пересылать логины и пароли.
